# Biology image insertion map

> This is the production hand-off for the 52 in-page image notes. The note's exact position is the insertion anchor: when an asset is approved, replace the matching `<aside id="image-brief-ID">` with a semantic `<figure>` at the same location. Do not append a duplicate image elsewhere.

## Asset conventions

- Store generated assets under `biology/images/generated/` using the exact filenames below.
- Format: WebP for generated raster artwork; use the specified aspect ratio as the composition target.
- Use responsive images (`width: 100%`, intrinsic aspect ratio, lazy loading below the fold) and semantic `<figure>/<figcaption>`.
- Provide meaningful Russian and English `alt` text; captions should identify the subject and avoid unsupported species, locality, scale or range claims.
- Keep the original note until the image has passed scientific/editorial review and the file is integrated. Then replace the note, update the central checklist from `[ ]` to `[x]`, and record provenance/credits where relevant.
- Paths shown for page-level notes are relative to the HTML page; the central asset directory is `biology/images/generated/`.
