# Обработка педагогических замечаний — физический атлас
# Teacher Feedback Moderation Workflow — Physics Atlas

## 1. Статус / Status

Это инструкция для будущего пилота. Сейчас приём ответов выключен; очередь модерации не создана и реальные данные не собираются. / This guide is for a future pilot. Intake is disabled; no moderation queue exists and no real responses are collected.

## 2. Порядок обработки / Workflow

1. **Регистрация в закрытой очереди / Private intake:** только после отдельного разрешения и запуска защищённого endpoint. Присвоить внутренний ID; хранить контакты отдельно от текста замечания.
2. **Классификация / Classification:** предмет Physics; категория (научная ошибка, источник/данные, объяснение/методика, перевод, визуал, лаборатория/техника, доступность/мобильность, предложение); приоритет автора.
3. **Локализация / Locate:** проверить главу, подраздел, язык, формулу, график, лабораторию, URL или якорь. Если данных недостаточно — запросить уточнение, если контакт предоставлен.
4. **Проверка / Verification:** воспроизвести утверждение или расчёт. Для физики проверить определения величин, знаки и обозначения, единицы СИ, размерности, начальные условия, допущения модели, оси/масштабы графика, алгоритм вычислений и физический смысл результата.
5. **Источники / Evidence:** сверить с надёжными учебниками, учебными программами, стандартами единиц и первичными/авторитетными источниками. Записать библиографические данные и конкретное подтверждение. Не считать ссылку учителя автоматически достаточным доказательством.
6. **Раздельная оценка / Separate assessment:** научную/фактическую ошибку оценивать отдельно от педагогического предпочтения, сложности текста или предложения о новом содержании.
7. **Решение / Decision:** исправить; принять как рекомендацию; запросить уточнение; отложить; отклонить с объяснением; объединить как дубликат. При критической ошибке — приоритетная внутренняя проверка, но не автоматическая публикация исправления.
8. **Изменение / Change:** правку делает ответственный редактор в ветке Physics. Синхронизировать русскую и английскую версии. Добавить запись в журнал: ID замечания, решение, источники, файлы, дата и commit SHA.
9. **Ответ / Reply:** если контакт предоставлен, сообщить результат нейтрально. Не раскрывать внутренние заметки модерации.
10. **Закрытие / Close:** указать итоговый статус и основание; сохранить минимально необходимую запись по утверждённой политике хранения.

## 3. Статусы / Status labels

- Received — получено (только после реального запуска)
- Under review — проверяется
- Confirmed — подтверждено источниками/воспроизведением
- Correction in progress — исправление готовится
- Fixed — исправлено; указан commit/release
- Not confirmed — не подтверждено
- Deferred — отложено
- Duplicate — дубликат
- Needs clarification — требуется уточнение

## 4. Контроль научной корректности / Scientific integrity checks

Для формул: размерность обеих частей, обозначения, индексы, знаки, условия применимости и единицы результата.  
Для расчётов: независимый пересчёт, крайние/нулевые значения, округление и обработка некорректного ввода.  
Для лабораторий: соответствие математической модели физическому явлению, параметры и начальные условия, ожидаемое направление изменения, графики и результаты.  
Для графиков: подписи осей, единицы, шкалы, легенда, смысл зависимости и отсутствие вводящих в заблуждение визуальных эффектов.  
Для переводов: смысловая эквивалентность, общепринятые термины и отсутствие расхождений между RU/EN.

## 5. Публикация и приватность / Publication and privacy

Публично можно показывать только очищенное описание проблемы и статус, если владелец проекта отдельно одобрит публичную страницу. Не публиковать email, личную переписку, имя, школу или цитату без отдельного явного согласия. Не выдавать самоотчёт о квалификации за проверенную аккредитацию. Удалять/скрывать спам, оскорбления, рекламу и персональные данные.

## 7. Запрет автоматического исправления / No automatic edits

Ни одна рекомендация или заявленная ошибка не меняет атлас автоматически. Решение принимает редактор после проверки доказательств. При недостаточных данных формулировка остаётся без изменений до уточнения либо помечается как отложенная.
