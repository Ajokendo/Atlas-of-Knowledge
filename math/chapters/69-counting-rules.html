Правило произведенияThe product rule

Если выбор состоит из последовательных шагов, и на первом шаге n₁ способов, на втором n₂ (при любом первом) и т. д., то всего n₁ · n₂ · … · nₖ способов. Пример: код из 4 цифр — 10⁴ = 10 000 вариантов (с повторами).

If a choice consists of successive steps with n₁ ways on the first, n₂ on the second (for any first), and so on, there are n₁ · n₂ · … · nₖ ways in total. Example: a 4-digit code — 10⁴ = 10,000 options (with repeats).

Правило суммыThe sum rule

Если объект можно выбрать либо из одного набора (n способов), либо из другого (m способов), и наборы не пересекаются, то всего n + m. При пересечении: |A ∪ B| = |A| + |B| − |A ∩ B| — общие элементы нужно вычесть, чтобы не считать дважды.

If an object can be chosen either from one set (n ways) or from another (m ways) and the sets do not overlap then there are n + m in total. With overlap: |A ∪ B| = |A| + |B| − |A ∩ B| — common elements are subtracted so as not to count twice.

|A ∪ B| = |A| + |B| − |A ∩ B||A ∪ B| = |A| + |B| − |A ∩ B|

Рост числа вариантовGrowth of options

Число вариантов растёт очень быстро: пароль из 8 символов-цифр — 10⁸ (100 млн), из 8 букв и цифр (36 символов) — около 2,8 · 10¹². Поэтому длина пароля важнее хитрости. Без повторов: d · (d−1) · … · (d−n+1).

The number of options grows very fast: an 8-digit password — 10⁸ (100 million), 8 letters and digits (36 symbols) — about 2.8 · 10¹². So length matters more than cleverness. Without repeats: d · (d−1) · … · (d−n+1).

Разгадка: 24 обедаThe answer: 24 lunches

К каждому из 3 первых блюд подходит любое из 4 вторых — это 3 · 4 = 12 пар; к каждой пары любой из 2 напитков — 12 · 2 = 24 обеда. Такой подсчёт называют принципом (правилом) умножения. Его удобно представлять деревом: каждая ветвь — один вариант. (Меню придумано для задачи.)

Each of the 3 first courses goes with any of the 4 main courses — 3 · 4 = 12 pairs; with each pair any of 2 drinks — 12 · 2 = 24 lunches. This counting is called the multiplication principle. It is handy to picture it as a tree: each branch is one option. (The menu is invented for the exercise.)
