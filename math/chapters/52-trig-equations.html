ЗАГАДКА В НАЧАЛЕOPENING PUZZLE

Высота прилива в порту описывается функцией h(t) = 2 + sin(t), где t — время в часах от начала отсчёта (условно). Корабль может зайти в порт при высоте воды не меньше 2,5 м.

Когда это возможно?

The tide height in a port is described by h(t) = 2 + sin(t) where t is the time in hours from a starting point (illustratively). A ship can enter the port when the water is at least 2.5 m.

Уравнение sin x = aThe equation sin x = a

При |a| ≤ 1 решения: x = arcsin a + 2πk и x = π − arcsin a + 2πk, k — любое целое. При |a| > 1 решений нет. Частные случаи: sin x = 0 → x = πk; sin x = 1 → x = π/2 + 2πk. arcsin a — угол из [−π/2; π/2], синус которого равен a.

For |a| ≤ 1 the solutions are x = arcsin a + 2πk and x = π − arcsin a + 2πk with k any integer. For |a| > 1 there are none. Special cases: sin x = 0 → x = πk; sin x = 1 → x = π/2 + 2πk. arcsin a is the angle in [−π/2; π/2] whose sine is a.

x = (−1)ᵏ arcsin a + πkx = (−1)ᵏ arcsin a + πk

На окружности две точки имеют одну и ту же ординату a. Каждую можно повернуть на полный оборот 2πk — получаем бесконечную серию.On the circle two points have the same ordinate a. Each can be rotated by a full turn 2πk — we get an infinite family.

Уравнение cos x = aThe equation cos x = a

При |a| ≤ 1: x = ± arccos a + 2πk. Графически — точки пересечения косинусоиды с прямой y = a. Частные: cos x = 0 → x = π/2 + πk; cos x = 1 → x = 2πk; cos x = −1 → x = π + 2πk.

For |a| ≤ 1: x = ± arccos a + 2πk. Graphically — intersection points of the cosine curve with the line y = a. Special cases: cos x = 0 → x = π/2 + πk; cos x = 1 → x = 2πk; cos x = −1 → x = π + 2πk.

Уравнение tan x = aThe equation tan x = a

При любом a: x = arctan a + πk. Для сложных уравнений используют замену: 2 sin²x − sin x − 1 = 0 при t = sin x даёт квадратное 2t² − t − 1 = 0 с корнями 1 и −1/2.

For any a: x = arctan a + πk. For complex equations we use a substitution: 2 sin²x − sin x − 1 = 0 with t = sin x gives the quadratic 2t² − t − 1 = 0 with roots 1 and −1/2.

Разгадка: sin t ≥ 0,5The answer: sin t ≥ 0.5

Нужно 2 + sin t ≥ 2,5, то есть sin t ≥ 0,5. Граничные значения находим из уравнения sin t = 0,5: t = π/6 и t = 5π/6 (плюс полные периоды 2πk). Между ними синус больше 0,5, то есть окно захода — π/6 ≤ t ≤ 5π/6, это около 2,1 ч за каждый период. Решения уравнения задают границы решения неравенства.

We need 2 + sin t ≥ 2.5, i.e. sin t ≥ 0.5. The boundary values come from the equation sin t = 0.5: t = π/6 and t = 5π/6 (plus full periods 2πk). Between them the sine exceeds 0.5, so the window is π/6 ≤ t ≤ 5π/6, about 2.1 h per period. The solutions of the equation give the boundaries of the inequality’s solution.
