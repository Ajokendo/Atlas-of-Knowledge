МонотонностьMonotonicity

Если f′(x) > 0 на промежутке, функция там возрастает; если f′(x) < 0 — убывает. Чтобы найти промежутки, решают f′ = 0 и смотрят знаки между корнями. Для f = x³ − 3x: f′ = 3(x − 1)(x + 1), промежутки возрастания (−∞; −1) и (1; +∞).

If f′(x) > 0 on an interval the function increases there; if f′(x) < 0 it decreases. To find the intervals solve f′ = 0 and check signs between the roots. For f = x³ − 3x: f′ = 3(x − 1)(x + 1), increasing on (−∞; −1) and (1; +∞).

f′ > 0 ⇒ возрастаетf′ > 0 ⇒ increases

Знак производной определяет поведение функции: f′ > 0 — возрастает (зелёное), f′ < 0 — убывает (красное).The sign of the derivative determines the behaviour: f′ > 0 — increases, f′ < 0 — decreases.

ЭкстремумыExtrema

Точки, где f′ = 0 или не существует, — «подозрительные» (критические). Если f′ меняет знак с + на −, это локальный максимум; с − на + — минимум. Если знак не меняется (как у x³ в нуле), экстремума нет.

Points where f′ = 0 or does not exist are “suspects” (critical points). If f′ changes sign from + to − it is a local maximum; from − to + a minimum. If the sign does not change (like x³ at zero) there is no extremum.

f′ = 0 — критическая точкаf′ = 0 — critical point

Точка, где f′ меняет знак с плюса на минус, — локальный максимум; с минуса на плюс — минимум. Параметр c поднимает весь график.A point where f′ changes sign from plus to minus is a local maximum; from minus to plus — a minimum. The parameter c lifts the whole graph.

Наибольшее и наименьшее значенияGreatest and least values

На отрезке [a; b] наибольшее и наименьшее значения непрерывной функции достигаются либо в критических точках, либо на концах. Задача на оптимизацию: записать величину как функцию одной переменной, найти f′ = 0, проверить концы и смысл ответа.

On a segment [a; b] the greatest and least values of a continuous function are reached either at critical points or at the endpoints. An optimisation problem: write the quantity as a function of one variable, find f′ = 0, check the endpoints and the sense of the answer.

max/min — в критических точках или на концахmax/min — at critical points or endpoints

Answer: (2; +∞).

Задача 2. МинимумProblem 2. Minimum

Найдите точку минимума x² − 4x.

Дано:

f′ = 0 при x = 2, знак − → +. Минимум в x = 2, f(2) = −4.

Ответ: x = 2, f = −4.

Find the minimum point of x² − 4x.

Given:

f′ = 0 при x = 2, знак − → +. Минимум в x = 2, f(2) = −4.

Answer: x = 2, f = −4.

Разгадка: 25 м в глубину и 50 м вдоль рекиThe answer: 25 m deep and 50 m along the river

Пусть две стороны забора, перпендикулярные реке, равны x, тогда третья сторона 100 − 2x, площадь S = x(100 − 2x) = 100x − 2x². Производная S′ = 100 − 4x равна нулю при x = 25. Тогда вдоль реки 50 м, а S = 1250 м². S′ положительна до 25 и отрицательна после, значит, это максимум. (Сюжет и числа придуманы для учебной задачи.)

Let the two fence sides perpendicular to the river be x; the third is 100 − 2x and the area S = x(100 − 2x) = 100x − 2x². The derivative S′ = 100 − 4x is zero at x = 25. Then the side along the river is 50 m and S = 1250 m². S′ is positive before 25 and negative after, so this is a maximum. (The story and numbers are invented for the exercise.)
