Перестановки и факториалPermutations and the factorial

n! = 1 · 2 · … · n — число перестановок n разных предметов; 0! = 1. Рост очень быстрый: 5! = 120, 10! = 3 628 800. Если среди предметов есть одинаковые, делят на факториалы их количеств: слово «МАМА» — 4!/(2!·2!) = 6 перестановок.

n! = 1 · 2 · … · n is the number of permutations of n different objects; 0! = 1. The growth is very fast: 5! = 120, 10! = 3,628,800. If some objects are identical we divide by factorials of their counts: the word “MAMA” gives 4!/(2!·2!) = 6 permutations.

Размещения и сочетанияArrangements and combinations

Размещения (порядок важен): A(n, k) = n!/(n − k)!. Сочетания (порядок не важен): C(n, k) = n! / (k!·(n − k)!). Свойства: C(n, k) = C(n, n − k); C(n, 0) = 1; A(n, k) = C(n, k)·k!.

Arrangements (order matters): A(n, k) = n!/(n − k)!. Combinations (order does not matter): C(n, k) = n! / (k!·(n − k)!). Properties: C(n, k) = C(n, n − k); C(n, 0) = 1; A(n, k) = C(n, k)·k!.

C(n, k) = n! / (k!(n − k)!)C(n, k) = n! / (k!(n − k)!)

If only the set matters (a team) — combinations: each combination gives k! arrangements.

Треугольник Паскаля и биномPascal’s triangle and the binomial

C(n, k) = C(n − 1, k − 1) + C(n − 1, k) — правило треугольника. Формула бинома Ньютона: (a + b)ⁿ = Σ C(n, k)·aⁿ⁻ᵏ·bᵏ. Например, (a + b)³ = a³ + 3a²b + 3ab² + b³ — коэффициенты 1, 3, 3, 1 — третья строка. Сумма строки n равна 2ⁿ: столько же подмножеств у n-элементного множества.

C(n, k) = C(n − 1, k − 1) + C(n − 1, k) — the triangle rule. Newton’s binomial formula: (a + b)ⁿ = Σ C(n, k)·aⁿ⁻ᵏ·bᵏ. For example (a + b)³ = a³ + 3a²b + 3ab² + b³ — the coefficients 1, 3, 3, 1 are the third row. The sum of row n is 2ⁿ: the number of subsets of an n-element set.

The sum of row n is 2ⁿ and the numbers are the coefficients of the expansion of (a + b)ⁿ.

Разгадка: 1140 команд и 6840 назначенийThe answer: 1140 teams and 6840 assignments

Если важен только состав, это сочетания: C(20, 3) = 20·19·18 / (1·2·3) = 1140. Если важна ещё и роль, порядок существен: размещения A(20, 3) = 20·19·18 = 6840. Размещений в 3! = 6 раз больше, чем сочетаний: одну и ту же тройку можно «разыграть по ролям» шестью способами.

If only the membership matters these are combinations: C(20, 3) = 20·19·18 / (1·2·3) = 1140. If the role matters too, order is essential: arrangements A(20, 3) = 20·19·18 = 6840. There are 3! = 6 times as many arrangements as combinations: the same trio can be “cast into roles” in six ways.
