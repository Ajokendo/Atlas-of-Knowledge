Последовательность и прогрессияSequences and progressions

Числовая последовательность — числа, пронумерованные натуральными числами: a₁, a₂, a₃, … Арифметическая прогрессия — последовательность, в которой каждый член получается из предыдущего прибавлением одного и того же числа d (разности): aₙ = a₁ + (n − 1)d. Точки (n; aₙ) лежат на одной прямой.

A number sequence is numbers labelled by naturals: a₁, a₂, a₃, … An arithmetic progression is a sequence in which each term is got from the previous one by adding the same number d (the difference): aₙ = a₁ + (n − 1)d. The points (n; aₙ) lie on one line.

aₙ = a₁ + (n − 1)daₙ = a₁ + (n − 1)d

Сумма членовThe sum of terms

Сумма первых n членов S = (a₁ + aₙ)·n / 2 или S = (2a₁ + (n − 1)d)·n / 2. Идея Гаусса: пары «первый + последний», «второй + предпоследний» дают одну и ту же сумму. Среднее арифметическое двух соседних членов равно члену между ними.

The sum of the first n terms S = (a₁ + aₙ)·n / 2 or S = (2a₁ + (n − 1)d)·n / 2. Gauss’s idea: the pairs “first + last”, “second + second last” give the same sum. The arithmetic mean of two neighbouring terms equals the term between them.

S = (a₁ + aₙ)·n/2S = (a₁ + aₙ)·n/2

ПрименениеApplications

Арифметические прогрессии описывают равномерный рост: ряды в амфитеатре, ступени лестницы, равные ежемесячные взносы. Решая задачи, определяют, что известно: a₁, d, n, aₙ или S, и выбирают формулу.

Arithmetic progressions describe steady growth: rows in an amphitheatre, stair steps, equal monthly payments. In problems we determine what is known: a₁, d, n, aₙ or S, and choose a formula.

1 + 2 + … + n = n(n + 1)/21 + 2 + … + n = n(n + 1)/2

Разгадка: 5 050The answer: 5,050

Он заметил, что 1 + 100 = 101, 2 + 99 = 101, 3 + 98 = 101 и так далее: таких пар 50. Значит, сумма равна 50 · 101 = 5 050. Это формула суммы арифметической прогрессии: S = (a₁ + aₙ) · n / 2 = (1 + 100) · 100 / 2 = 5 050.

He noticed that 1 + 100 = 101, 2 + 99 = 101, 3 + 98 = 101 and so on: there are 50 such pairs. So the sum is 50 · 101 = 5,050. This is the formula for the sum of an arithmetic progression: S = (a₁ + aₙ) · n / 2 = (1 + 100) · 100 / 2 = 5,050.
