Координаты в пространствеCoordinates in space

Три взаимно перпендикулярные оси x, y, z задают систему координат. Точка M(x; y; z). Расстояние от начала: OM = √(x² + y² + z²). Координатные плоскости: xy (z = 0), xz (y = 0), yz (x = 0).

Three mutually perpendicular axes x, y, z define a coordinate system. A point M(x; y; z). The distance from the origin: OM = √(x² + y² + z²). Coordinate planes: xy (z = 0), xz (y = 0), yz (x = 0).

OM = √(x² + y² + z²)OM = √(x² + y² + z²)

Вектор и расстояниеVector and distance

Вектор AB = (x₂ − x₁; y₂ − y₁; z₂ − z₁). |AB| = √((x₂ − x₁)² + (y₂ − y₁)² + (z₂ − z₁)²). Середина отрезка: ((x₁ + x₂)/2; (y₁ + y₂)/2; (z₁ + z₂)/2). Сложение векторов и умножение на число — покоординатно, как на плоскости.

The vector AB = (x₂ − x₁; y₂ − y₁; z₂ − z₁). |AB| = √((x₂ − x₁)² + (y₂ − y₁)² + (z₂ − z₁)²). The midpoint of a segment: ((x₁ + x₂)/2; (y₁ + y₂)/2; (z₁ + z₂)/2). Addition of vectors and multiplication by a number are coordinatewise, as in the plane.

|AB| = √(Δx² + Δy² + Δz²)|AB| = √(Δx² + Δy² + Δz²)

Скалярное произведениеThe dot product

a·b = x₁x₂ + y₁y₂ + z₁z₂ = |a||b| cos φ. Отсюда cos φ = a·b / (|a||b|). Векторы перпендикулярны, когда a·b = 0. Так находят углы в многогранниках: введите координаты вершин и сосчитайте.

a·b = x₁x₂ + y₁y₂ + z₁z₂ = |a||b| cos φ. Hence cos φ = a·b / (|a||b|). Vectors are perpendicular when a·b = 0. This is how angles in polyhedra are found: introduce coordinates of the vertices and compute.

Разгадка: 130 мThe answer: 130 m

По горизонтали дрон сместился на √(30² + 40²) = 50 м, потом поднялся на 120 м: √(50² + 120²) = 130 м. Это та же формула расстояния √(x² + y² + z²) — теорема Пифагора, применённая дважды. (Числа подобраны так, чтобы корни получились целыми; сюжет условный.)

Horizontally the drone moved √(30² + 40²) = 50 m, then rose 120 m: √(50² + 120²) = 130 m. This is the same distance formula √(x² + y² + z²) — the Pythagorean theorem applied twice. (The numbers are chosen so that the roots are integers; the story is illustrative.)
