Формула корнейThe root formula

Уравнение ax² + bx + c = 0 (a ≠ 0). Дискриминант D = b² − 4ac. Если D > 0, два корня x = (−b ± √D)/(2a); если D = 0, один корень x = −b/(2a); если D < 0, действительных корней нет. Неполные уравнения (b = 0 или c = 0) решают проще: x² = 9, x(x − 4) = 0.

The equation ax² + bx + c = 0 (a ≠ 0). The discriminant D = b² − 4ac. If D > 0 there are two roots x = (−b ± √D)/(2a); if D = 0 one root x = −b/(2a); if D < 0 there are no real roots. Incomplete equations (b = 0 or c = 0) are easier: x² = 9, x(x − 4) = 0.

x = (−b ± √D) / 2ax = (−b ± √D) / 2a

Теорема ВиетаVieta’s theorem

Для приведённого уравнения x² + bx + c = 0 корни связаны с коэффициентами: x₁ + x₂ = −b, x₁ · x₂ = c. Отсюда быстро подбирают целые корни: ищут два числа с суммой −b и произведением c. Квадратный трёхчлен раскладывают: ax² + bx + c = a(x − x₁)(x − x₂).

For the reduced equation x² + bx + c = 0 the roots are tied to the coefficients: x₁ + x₂ = −b, x₁ · x₂ = c. So integer roots are quickly guessed: look for two numbers with sum −b and product c. A quadratic trinomial factorises: ax² + bx + c = a(x − x₁)(x − x₂).

x₁ + x₂ = −b; x₁x₂ = cx₁ + x₂ = −b; x₁x₂ = c

Задачи с квадратным уравнениемProblems with a quadratic equation

Квадратные уравнения встречаются в задачах о движении под действием силы тяжести, площадях, прибыли. Решив, проверяют корни по смыслу: время и длина не бывают отрицательными.

Quadratic equations appear in problems of motion under gravity, areas, profit. After solving, the roots are checked against the meaning: time and length are not negative.

The ball lands when h = 0: 2 + 20t − 5t² = 0, i.e. 5t² − 20t − 2 = 0. D = 400 + 40 = 440, t = (20 ± √440)/10. The positive root t = (20 + 20.98)/10 ≈ 4.1 s. The second root is negative — it does not fit the problem. A quadratic equation gives two roots but we must check which makes sense.
