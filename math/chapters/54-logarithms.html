Что такое логарифмWhat a logarithm is

logₐ b = x означает aˣ = b (a > 0, a ≠ 1, b > 0). Например, log₂ 8 = 3, потому что 2³ = 8; log₁₀ 1000 = 3. Основное логарифмическое тождество: a^(logₐ b) = b. Десятичный логарифм lg b — по основанию 10, натуральный ln b — по основанию e.

logₐ b = x means aˣ = b (a > 0, a ≠ 1, b > 0). For example log₂ 8 = 3 because 2³ = 8; log₁₀ 1000 = 3. The basic identity: a^(logₐ b) = b. The common logarithm lg b has base 10, the natural one ln b has base e.

ГрафикThe graph

Логарифмическая функция y = logₐ x — обратная к y = aˣ. Определена при x > 0, проходит через (1; 0), при a > 1 возрастает: медленно, но без предела. Ось y — вертикальная асимптота.

The logarithmic function y = logₐ x is the inverse of y = aˣ. It is defined for x > 0, passes through (1; 0) and for a > 1 increases slowly but without bound. The y-axis is a vertical asymptote.

Разгадка: шкала логарифмическаяThe answer: the scale is logarithmic

Магнитуда — логарифм измеренной величины: рост на единицу означает, что амплитуда колебаний вырастает в 10 раз (энергия — примерно в 32 раза). Поэтому разница в 4 единицы — это 10⁴ = 10 000 раз по амплитуде и около 10⁶ по энергии. Логарифмические шкалы используют там, где величины различаются в миллионы раз: магнитуда, децибелы, pH.

Magnitude is a logarithm of the measured quantity: one unit means the amplitude grows 10 times (energy about 32 times). So a 4-unit difference is 10⁴ = 10,000 times in amplitude and about 10⁶ in energy. Logarithmic scales are used where quantities differ by millions: magnitude, decibels, pH.
