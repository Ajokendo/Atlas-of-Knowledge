Переменная и значение выраженияA variable and the value of an expression

Буквенное выражение — запись из чисел, букв и знаков действий. Чтобы найти его значение, подставляют числа вместо букв и выполняют действия по порядку. Выражение ax + b задаёт линейную зависимость; на графике это прямая.

A letter expression is a notation made of numbers, letters and operation signs. To find its value we substitute numbers for letters and perform the operations in order. The expression ax + b describes a linear dependence; on a graph it is a straight line.

a·x + bпри x = 12: 100 + 20·12 = 340at x = 12: 100 + 20·12 = 340

Подобные слагаемыеLike terms

Подобные слагаемые отличаются только числовым множителем (коэффициентом): 5x и −2x. Их складывают: 5x − 2x = 3x. Слагаемые 3x и 3 — не подобные: одно с буквой, другое без, их не объединить.

Like terms differ only in the numerical factor (the coefficient): 5x and −2x. They are added: 5x − 2x = 3x. The terms 3x and 3 are not like: one has a letter, the other does not; they cannot be merged.

Раскрытие скобокExpanding brackets

Распределительный закон: k(a + b) = ka + kb. Если перед скобками знак «−», знаки внутри меняются на противоположные: −(a − b) = −a + b. Закон хорошо видно на площади: большой прямоугольник состоит из двух частей.

The distributive law: k(a + b) = ka + kb. If there is a “−” before the brackets, the signs inside change: −(a − b) = −a + b. The law is visible on an area: a large rectangle consists of two parts.

k(a + b) = ka + kbk(a + b) = ka + kb

Разгадка: 100 + 20x; 340 сомовThe answer: 100 + 20x; 340 som

Если поездка x километров, то цена равна 100 + 20x. Одно выражение заменяет таблицу цен для любого расстояния. При x = 12: 100 + 20 · 12 = 100 + 240 = 340 сомов. Буква x — переменная: вместо неё можно подставлять разные числа.

If the ride is x kilometres, the cost is 100 + 20x. One expression replaces a price table for any distance. At x = 12: 100 + 20 · 12 = 100 + 240 = 340 som. The letter x is a variable: different numbers can be put in its place.
