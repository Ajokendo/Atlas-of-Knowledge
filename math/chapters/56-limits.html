Предел последовательностиLimit of a sequence

Число A — предел последовательности aₙ, если для любого сколь угодно малого ε, начиная с некоторого номера, все члены отличаются от A меньше чем на ε. Пишут lim aₙ = A. Например, lim 1/n = 0; lim (2n + 1)/n = 2. Последовательность 1, 2, 3, … предела не имеет — она растёт без границ.

A number A is the limit of a sequence aₙ if for any arbitrarily small ε, from some index on, all terms differ from A by less than ε. We write lim aₙ = A. For example lim 1/n = 0; lim (2n + 1)/n = 2. The sequence 1, 2, 3, … has no limit — it grows without bound.

lim aₙ = Alim aₙ = A

Члены последовательности могут приближаться к числу сколь угодно близко — это число называют пределом. Если приближения нет, предела нет.The terms of a sequence may approach a number as closely as we wish — that number is the limit. If they do not approach anything, there is no limit.

Предел функцииLimit of a function

lim f(x) при x → a — число, к которому приближается f(x), когда x приближается к a (но не равно a). Основные правила: предел суммы, произведения и частного равен сумме, произведению и частному пределов (знаменатель ≠ 0). Если подстановка даёт 0/0, нужно преобразовать выражение: (x² − 1)/(x − 1) = x + 1 → 2.

lim f(x) as x → a is the number f(x) approaches when x approaches a (but is not equal to a). Main rules: the limit of a sum, product and quotient is the sum, product and quotient of the limits (denominator ≠ 0). If substitution gives 0/0 we transform the expression: (x² − 1)/(x − 1) = x + 1 → 2.

(x² − 1)/(x − 1) → 2(x² − 1)/(x − 1) → 2

Функция (x² − 1)/(x − 1) в точке 1 не определена, но при x, близких к 1, значения близки к 2. Предел не зависит от того, определена ли функция в самой точке.The function (x² − 1)/(x − 1) is not defined at 1, but for x near 1 the values are near 2. The limit does not depend on whether the function is defined at the point itself.

НепрерывностьContinuity

Функция непрерывна в точке a, если lim f(x) = f(a). Многочлены, sin, cos, aˣ непрерывны всюду; 1/x разрывна в нуле. Непрерывные функции обладают важным свойством: если f(a) < 0 и f(b) > 0, то между a и b есть корень.

A function is continuous at a if lim f(x) = f(a). Polynomials, sin, cos, aˣ are continuous everywhere; 1/x is discontinuous at zero. Continuous functions have an important property: if f(a) < 0 and f(b) > 0 then there is a root between a and b.

lim f(x) = f(a)lim f(x) = f(a)

Разгадка: прыжков бесконечно много, а высота стремится к 0The answer: infinitely many bounces, and the height tends to 0

В идеальной модели высоты 1, 1/2, 1/4, 1/8… никогда не обращаются в ноль, но становятся меньше любого заданного числа — говорят, что предел высоты равен 0. Идея предела позволяет иметь дело с бесконечными процессами, не заканчивая их. (Настоящий мяч, конечно, останавливается — это идеальная модель.)

In the ideal model the heights 1, 1/2, 1/4, 1/8… never become zero but become smaller than any given number — we say the limit of the height is 0. The idea of a limit lets us handle infinite processes without finishing them. (A real ball stops, of course — this is an ideal model.)
