Уравнение и кореньAn equation and its root

Уравнение — равенство с неизвестным. Корень — значение неизвестного, при котором равенство верно. Решить уравнение — найти все корни. Самое надёжное — проверить: подставить корень в уравнение.

An equation is an equality with an unknown. A root is the value of the unknown for which the equality holds. To solve an equation is to find all roots. The most reliable thing is to check: substitute the root.

ax + b = cax + b = c

Решение по шагамSolving step by step

Правила: любое слагаемое можно перенести через знак «=», изменив его знак; обе части можно умножить или разделить на число, не равное нулю. Так ax + b = c превращается в ax = c − b, а затем x = (c − b)/a.

Rules: any term can be moved across “=” with its sign changed; both sides can be multiplied or divided by a nonzero number. So ax + b = c turns into ax = c − b and then x = (c − b)/a.

Задачи с уравнениемWord problems with an equation

План: 1) обозначить неизвестное буквой; 2) выразить через неё другие величины; 3) составить уравнение по условию; 4) решить; 5) проверить и записать ответ в единицах задачи. Следите за смыслом: количество билетов — целое число.

The plan: 1) denote the unknown by a letter; 2) express other quantities through it; 3) build an equation from the condition; 4) solve; 5) check and write the answer in the problem’s units. Mind the meaning: the number of tickets is a whole number.

цена · количество + плата = суммаprice · quantity + fee = total

Задача 1. Простое уравнениеProblem 1. A simple equation

Решите 5x − 7 = 18.

Дано: 5x = 18 + 7

5x = 25, x = 5. Проверка: 25 − 7 = 18.

Ответ: x = 5.

Solve 5x − 7 = 18.

Given: 5x = 18 + 7

5x = 25, x = 5. Проверка: 25 − 7 = 18.

Answer: x = 5.

Задача 2. Неизвестное с обеих сторонProblem 2. Unknown on both sides

Решите 3x + 4 = x + 10.

Дано: 3x − x = 10 − 4

2x = 6, x = 3.

Ответ: x = 3.

Solve 3x + 4 = x + 10.

Given: 3x − x = 10 − 4

2x = 6, x = 3.

Answer: x = 3.

Задача 4. ЗадачаProblem 4. A problem

Отару разделили так: в первой части на 12 овец больше, чем во второй; всего 100 овец. Сколько во второй?

Дано: x + (x + 12) = 100

2x = 88, x = 44.

A flock was split so that the first part has 12 more sheep than the second; there are 100 in all. How many in the second?

Given: x + (x + 12) = 100

2x = 88, x = 44.

Answer: 44 sheep.

Проверьте себяCheck yourself

Выберите ответ — сразу появится объяснение.Pick an answer — an explanation appears at once.

Разгадка: 30 сомовThe answer: 30 som

Пусть тетрадь стоит x сомов. Тогда 3x + 20 = 110. Вычтем 20 из обеих частей: 3x = 90. Разделим на 3: x = 30. Проверка: 3 · 30 + 20 = 110. Уравнение — как весы: что делаем с одной чашей, то делаем и с другой.

Let a notebook cost x som. Then 3x + 20 = 110. Subtract 20 from both sides: 3x = 90. Divide by 3: x = 30. Check: 3 · 30 + 20 = 110. An equation is like a balance: whatever we do to one pan we do to the other.
