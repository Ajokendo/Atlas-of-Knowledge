Прямая и параболаA line and a parabola

Система y = x², y = kx + b: подставляем y и получаем квадратное уравнение x² − kx − b = 0. D > 0 — две общие точки, D = 0 — касание, D < 0 — нет общих точек. Найденные x подставляют в одно из уравнений, чтобы найти y.

The system y = x², y = kx + b: substituting y gives the quadratic x² − kx − b = 0. D > 0 — two common points, D = 0 — tangency, D < 0 — none. The found x are substituted into one equation to find y.

x² = kx + bx² = kx + b

Прямая и окружностьA line and a circle

Система x² + y² = r², y = kx + b: подстановка даёт (1 + k²)x² + 2kbx + b² − r² = 0. Расстояние от начала координат до прямой d = |b|/√(1 + k²): d < r — две точки, d = r — касание, d > r — нет точек.

The system x² + y² = r², y = kx + b: substitution gives (1 + k²)x² + 2kbx + b² − r² = 0. The distance from the origin to the line d = |b|/√(1 + k²): d < r — two points, d = r — tangent, d > r — none.

d = |b|/√(1 + k²)d = |b|/√(1 + k²)

Метод Виета для суммы и произведенияVieta’s method for sum and product

Система x + y = s, xy = p равносильна тому, что x и y — корни t² − st + p = 0. Получаем две пары: (x₁; x₂) и (x₂; x₁). Если D < 0, решений нет. Такой приём называют симметрическим.

The system x + y = s, xy = p means that x and y are the roots of t² − st + p = 0. This gives two pairs: (x₁; x₂) and (x₂; x₁). If D < 0 there are no solutions. This trick is called symmetric.

t² − st + p = 0t² − st + p = 0

Разгадка: 3 и 4The answer: 3 and 4

Числа x и y — корни уравнения t² − 7t + 12 = 0 (по теореме Виета). D = 49 − 48 = 1, t = (7 ± 1)/2: 3 и 4. Проверка: 3 + 4 = 7, 3 · 4 = 12. Система из линейного и нелинейного уравнений сводится к квадратному уравнению подстановкой одного неизвестного в другое.

The numbers x and y are the roots of t² − 7t + 12 = 0 (by Vieta’s theorem). D = 49 − 48 = 1, t = (7 ± 1)/2: 3 and 4. Check: 3 + 4 = 7, 3 · 4 = 12. A system of a linear and a nonlinear equation reduces to a quadratic equation by substituting one unknown into the other.
