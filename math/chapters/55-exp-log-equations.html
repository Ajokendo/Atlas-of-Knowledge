Показательные уравненияExponential equations

Если основания приводятся к одинаковым: aᶠ = aᵍ ⇒ f = g, например 2ˣ = 32 ⇒ x = 5. Иначе логарифмируют: aˣ = b ⇒ x = logₐ b. Часто помогает замена t = aˣ: 4ˣ − 3·2ˣ + 2 = 0 → t² − 3t + 2 = 0 (t > 0).

If the bases can be made equal: aᶠ = aᵍ ⇒ f = g, e.g. 2ˣ = 32 ⇒ x = 5. Otherwise take logarithms: aˣ = b ⇒ x = logₐ b. A substitution t = aˣ often helps: 4ˣ − 3·2ˣ + 2 = 0 → t² − 3t + 2 = 0 (t > 0).

aˣ = b ⇒ x = logₐ baˣ = b ⇒ x = logₐ b

Логарифмические уравненияLogarithmic equations

logₐ f = logₐ g ⇒ f = g, но только при f > 0 и g > 0. Обязательно проверяйте область определения: log₂(x − 1) + log₂(x + 1) = 3 даёт x² − 1 = 8, x = ±3, но x = −3 не подходит — под логарифмом отрицательное число.

logₐ f = logₐ g ⇒ f = g, but only when f > 0 and g > 0. Always check the domain: log₂(x − 1) + log₂(x + 1) = 3 gives x² − 1 = 8, x = ±3, but x = −3 is rejected — the logarithm would get a negative number.

logₐ f = logₐ g ⇒ f = g > 0logₐ f = logₐ g ⇒ f = g > 0

ПриложенияApplications

Время роста или распада всегда ищется через логарифм: t = T · log₂(1/f) для полураспада и n = ln k / ln(1 + p/100) для роста. Показатели pH, децибелы и магнитуда — те же логарифмы.

The time of growth or decay is always found with a logarithm: t = T · log₂(1/f) for half-life and n = ln k / ln(1 + p/100) for growth. pH, decibels and magnitude are the same logarithms.
