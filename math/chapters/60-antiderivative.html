ОпределениеDefinition

Функция F — первообразная f на промежутке, если F′(x) = f(x). Все первообразные одной f отличаются на константу: F(x) + C. Множество всех первообразных называют неопределённым интегралом: ∫ f(x) dx = F(x) + C.

A function F is an antiderivative of f on an interval if F′(x) = f(x). All antiderivatives of one f differ by a constant: F(x) + C. The set of all antiderivatives is called the indefinite integral: ∫ f(x) dx = F(x) + C.

F′ = f ⇒ ∫ f dx = F + CF′ = f ⇒ ∫ f dx = F + C

Первообразная F для f — функция, у которой F′ = f. Для f(x) = 2x подходит x², но и x² + 1, и x² − 3: все они отличаются на постоянную C.An antiderivative F of f is a function with F′ = f. For f(x) = 2x the function x² works, and so do x² + 1 and x² − 3: they differ by a constant C.

Задача о движенииA motion problem

По ускорению a находят скорость v = ∫ a dt = v₀ + at, затем путь s = ∫ v dt = v₀t + at²/2. Постоянные находят по начальным условиям.

From acceleration a we find speed v = ∫ a dt = v₀ + at, then distance s = ∫ v dt = v₀t + at²/2. The constants are found from initial conditions.

v = v₀ + at; s = v₀t + at²/2v = v₀ + at; s = v₀t + at²/2

Скорость v(t) = v₀ + atSpeed v(t) = v₀ + at
Путь s(t) = v₀t + at²/2Distance s(t) = v₀t + at²/2
Проверка s′ = vCheck s′ = v

Скорость — производная пути, значит путь — первообразная скорости: s = v₀t + at²/2 (при s(0) = 0). Так получают формулы равноускоренного движения.Speed is the derivative of distance, so distance is an antiderivative of speed: s = v₀t + at²/2 (with s(0) = 0). This is how the uniform-acceleration formulas arise.

Разгадка: почти, нужна начальная точкаThe answer: almost — a starting point is needed

Скорость — производная положения, значит положение — первообразная скорости. Но первообразная определена с точностью до постоянной C: по скорости не узнать, откуда автобус выехал. Если известна начальная точка (s(0) = s₀), постоянная находится однозначно. Поэтому в ответе на «найдите первообразную» всегда пишут «+ C».

Speed is the derivative of position, so position is an antiderivative of speed. But an antiderivative is defined up to a constant C: from speed alone we cannot know where the bus started. If the initial point is known (s(0) = s₀) the constant is found uniquely. That is why the answer to “find the antiderivative” always has “+ C”.
