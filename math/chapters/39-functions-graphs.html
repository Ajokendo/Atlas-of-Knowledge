Определение функцииThe definition of a function

Функция — правило, которое каждому значению аргумента x из области определения ставит в соответствие единственное значение y. Задают функцию формулой, таблицей или графиком. График — множество точек (x; y). Вертикальная прямая пересекает график функции не более одного раза.

A function is a rule that assigns to each value of the argument x from the domain a single value y. A function is given by a formula, a table or a graph. The graph is the set of points (x; y). A vertical line meets the graph of a function at most once.

y = f(x)y = f(x)

Каждому допустимому входу функция ставит в соответствие ровно один выход. Не любое число допустимо: нельзя делить на нуль и извлекать корень из отрицательного.A function assigns exactly one output to each admissible input. Not every number is admissible: we cannot divide by zero or take the root of a negative number.

Преобразования графиковGraph transformations

По графику y = f(x) строят: y = f(x − h) — сдвиг на h вправо; y = f(x) + k — сдвиг на k вверх; y = a·f(x) — растяжение в |a| раз по вертикали, при a < 0 ещё и отражение относительно оси x. Это основа для чтения любых графиков.

From the graph y = f(x) we build: y = f(x − h) — a shift of h to the right; y = f(x) + k — a shift of k up; y = a·f(x) — a stretch by |a| vertically, and for a < 0 also a reflection in the x-axis. This is the basis for reading any graphs.

y = a·f(x − h) + ky = a·f(x − h) + k

Чтение графикаReading a graph

По графику находят значение функции при данном x, наибольшее и наименьшее значения, промежутки, где функция возрастает или убывает, нули (где y = 0). Функция возрастает, если большему x соответствует большее y.

From a graph we find the value of the function at a given x, the greatest and least values, the intervals where the function rises or falls and the zeros (where y = 0). A function is increasing if a greater x gives a greater y.

f(x₁) < f(x₂) при x₁ < x₂ — возрастаетf(x₁) < f(x₂) for x₁ < x₂ — increasing

Задача 4. СдвигProblem 4. A shift

Как получить график y = (x − 2)² + 3 из y = x²?

Дано:

Сдвинуть на 2 вправо и на 3 вверх.

Ответ: На 2 вправо, на 3 вверх.

How to get the graph y = (x − 2)² + 3 from y = x²?

Given:

Сдвинуть на 2 вправо и на 3 вверх.

Answer: 2 right, 3 up.

Разгадка: выход ровно одинThe answer: exactly one output

Вход — расстояние x, выход — цена y = 100 + 20x. Для каждого расстояния цена определена однозначно: ровно один выход. Это и есть функция. Если бы один вход давал две цены, это не было бы функцией. График такого соответствия — прямая; по нему можно прочесть цену для любого расстояния.

The input is the distance x, the output is the price y = 100 + 20x. For each distance the price is uniquely defined: exactly one output. That is a function. If one input gave two prices it would not be a function. The graph of this relation is a straight line; from it we can read the price for any distance.
