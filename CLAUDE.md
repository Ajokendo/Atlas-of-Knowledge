# Atlas of Knowledge — заметки для продолжения работы

## Цель
Бесплатный интерактивный атлас для всех школьников Кыргызстана. Первая аудитория — школа, где учатся дети автора: демо-версию покажут учителям-предметникам для отзыва.

## Решения (ноябрь 2026)
- Предметы делятся **по темам, а не по классам**. Учитель сам решает, какую тему давать по программе Министерства. У темы может быть пометка уровня («основы», «углублённо»). Учитываем реформу: интегрированный предмет «Илим» в 1–9 классах, отдельные физика, химия и биология в 10–12.
- Все предметы на **русском и английском**. Кыргызский — позже, нужны кыргызоведы-редакторы.
- **Физику пишем свою** в общем стиле атласа: явления Кыргызстана (комуз, юрта, кипение в горах, Иссык-Куль, Токтогульская ГЭС, землетрясения, ледники), лёгкие 2D-модели вместо тяжёлого 3D. Перевод американского Atlas of Physics (`chapters/`, `original-engine/`) убран с сайта и из `main` 09.11.2026; он остаётся в истории git (коммит до e91fedd включительно).
- Первый блок физики: 1) что изучает физика, измерения; 2) строение вещества; 3) движение и силы; 4) давление (Архимед, атмосфера); 5) работа, мощность, энергия; 6) простые механизмы. В каждой главе: загадка в начале, объяснение, формулы, 2D-модель, разобранные задачи, тест с объяснениями.
- Позже: математика, геометрия, астрономия.
- Картинки: схемы рисуем в SVG; реальные виды и места — только настоящие фото со свободной лицензией (Wikimedia Commons, iNaturalist) с автором; генерацию нейросетью не используем для научных изображений.
- Правила об источниках, картинках и авторстве — один короткий файл `SOURCES_AND_IMAGES.md` (с 10.11.2026; старые длинные регламенты заменены заглушками). Соблюдать при каждой главе: чужие фото только CC0 / CC BY / CC BY-SA с подписью и записью в `IMAGE_SOURCES.md` предмета; в конце главы — «Источники».
- Авторство: © 2026 Азамат Орозобеков (в английских текстах — Azamat Orozobekov) и участники проекта; код — MIT (`LICENSE`), тексты и схемы — CC BY 4.0 (`CONTENT_LICENSE.md`); честная пометка «подготовлено с помощью ИИ». Подпись — внизу каждой страницы, на языке страницы.

## Устройство
- Сайт — статический, GitHub Pages из `main` (`.github/workflows/pages.yml`). Главная — `index.html` (портал); `portal.html` только перенаправляет на неё.
- Рабочие ветки `workspace/*` слиты в `main` 09.11.2026. Дальше работаем в `main` (или в коротких ветках с последующим слиянием).
- География: исходники — `geography/chapters/*.md`; ученики читают `geography/read/*.html`. После правки глав: `python3 geography/scripts/build_reader.py`, затем закоммитить.
- Своя физика: `physics/index.html` (блок I, 6 глав) и `physics/chapters/NN-*.html`. Образец главы — `01-what-is-physics.html`: двуязычный текст через пары `data-l="ru"` / `data-l="en"`, язык хранится в `localStorage` (`atlas-lang`), модели — inline SVG + JS. Тест главы пишет результат в `atlas-physics-quiz-v1` — его показывает `progress.html`. Новую главу добавлять также в `physics/index.html`, `catalog.html` и `progress.html`.
- Проверки: `node .github/scripts/check-local-links.mjs`, `node .github/scripts/check-inline-js.mjs` (портал и физика), `node chemistry/checks.mjs`, `node biology/checks.mjs`.
