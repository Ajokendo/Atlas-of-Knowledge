# Geography — Image Sources and Visual Asset Register

**Snapshot:** 4 November 2026  
**Branch:** `workspace/geography`  
**Scope:** Chapters 01–02 only  
**Policy:** search for an existing scientifically suitable image first; verify the individual asset's rights and attribution; create or generate a replacement only when no suitable reusable image is found.

## Status key

- **Pending search:** no specific candidate asset has been selected.
- **Candidate source:** a relevant institutional collection or educational resource has been identified, but no individual asset has passed rights and scientific review.
- **Rights checked:** the exact asset's licence/terms and attribution requirements have been recorded.
- **Approved:** science, rights, attribution, language and accessibility checks passed.
- **Integrated:** approved asset is committed to the site and its source metadata is recorded.

A site's general copyright statement is not a licence for every image on that site. Rights must be checked at the individual asset level. Public-domain status must also be confirmed for the exact media item, not inferred from the institution's name.

## Required metadata for every approved asset

- Visual ID and chapter/section.
- Exact source asset page and direct file link.
- Creator/photographer and copyright holder where stated.
- Exact licence or public-domain basis, including version and required attribution.
- Access date.
- Scientific fit and any data date, scale, projection or geographic coverage.
- Russian and English caption.
- Russian and English alt text.
- Integration path and commit SHA.
